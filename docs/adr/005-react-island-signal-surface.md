# ADR-005: React added as a single-page island (Signal & Surface)

Date: 2026-08-08 · Status: accepted, outcome pending review

## Context

ADR-001 committed this site to zero client-side framework, static HTML,
near-zero JavaScript — the reason every page held a Lighthouse performance
score ≥95 through 17 shipped versions. Sahil provided a complete React
component, generated by another tool, with explicit instructions to deploy
it exactly as given as a new version of the portfolio.

The component as given was incomplete: no stylesheet, image paths pointing
to storage this project has no access to, and built as a single-page React
app with logic (`useState`, `useEffect`, pointer tracking, scroll-based
section detection) that requires client-side hydration.

## Decision

Added `@astrojs/react` as an Astro integration, scoped to one page
(`/signal-surface/`) — not the whole site. The given component ships
verbatim except for two forced technical fixes: asset paths repointed from
the inaccessible `/manus-storage/` to placeholder SVGs pending real
exports from Sahil, and two lucide-react icon imports (`Github`,
`Linkedin`) substituted for `ArrowUpRight`, since the installed icon
library version no longer exports those brand icons. A complete stylesheet
was authored from scratch, since none was provided, inferring intent from
class names and the component's own design-system comment ("cobalt
signals", "warm editorial").

**Update, same day:** Sahil confirmed the fonts didn't match the real
Manus-hosted deployment. Investigation (the site's actual `<head>` source,
provided directly, plus its compiled CSS bundle fetched and read) found
real, verifiable design tokens: fonts are Space Grotesk (sans, used for
everything — no serif) and DM Mono, background `#f7f4ee`. The stylesheet
was corrected to match, self-hosted via Fontsource per the site's existing
GDPR-safe pattern (no Google Fonts CDN). Given the fix directly resolved
Sahil's specific concern and he'd already asked repeatedly for this to be
the actual Home, it was promoted to `/` — the previous module-grid Home is
archived at `src/pages/_archive/index-v1-module-grid.astro.bak`, not
deleted. The Impressum/Datenschutz links (absent from the original
component, legally required for a Germany-operated site) were added to
its footer as a hard requirement independent of the design decision.

**What's still unverified:** exact per-element color and spacing choices
beyond the font/background tokens confirmed above. Tailwind's full default
color palette is present in the compiled CSS, but which specific shades
are actually applied to which elements can't be confirmed without a
JS-rendering browser tool, which disconnected mid-session. The cobalt/
coral accents are a reasoned approximation, not a confirmed match.

## Consequences

- This is the first page on the site with a real client-side JavaScript
  cost: ~68KB gzipped (React runtime + the component), against a sitewide
  budget that was previously ≤50KB *total*. `lighthouserc.json` was
  updated to explicitly test this URL — without that change, CI would
  likely have only ever tested the root page and reported green without
  evaluating this page at all, which would have been a false signal.
- If Sahil chooses to promote this to the actual Home, the near-zero-JS
  claim in this repo's own colophon/ADR-001 needs to be revisited honestly
  rather than left standing while no longer true.
- The rest of the site — About, Work, the case studies, CV, legal pages,
  bilingual routing — is untouched and still zero-framework.
